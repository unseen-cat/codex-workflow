# Same Page

Use this skill when the user wants the previous message re-explained.

The reply should restate the key claims, the evidence behind them, and the confidence level for each material point.

## How to answer

- Re-read your most recent substantive message.
- Pull out the decisions, facts, and recommendations.
- Choose a structure that fits the shape of the message.
- Cite specific evidence for each important claim.
- Use a confidence label when a claim is inferred rather than directly verified.

## Required shape

- Evidence with confidence.
- A format that matches the discussion, not a fixed template.
- At least one ASCII diagram when it helps the reader follow the logic.
- A short close that names any remaining uncertainty.

## Good fits for different messages

- One main decision: short narrative plus one diagram.
- Several independent claims: compact table plus evidence notes.
- Comparison: side-by-side summary table.
- Process or flow: sequence diagram first, then evidence.
- Debugging: timeline of how the conclusion was reached.

## What not to do

- Do not hand-wave.
- Do not leave out evidence for material claims.
- Do not use a rigid template when another shape would be clearer.
- Do not skip the diagram if it clarifies the answer.
